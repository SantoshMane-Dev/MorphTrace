# MorphTrace

## Digital Image Forensics & Manipulation Detection

MorphTrace is a web-based digital image forensics application designed
to analyze images using multiple forensic techniques and provide
explainable evidence about potential manipulation.

## Core Objectives

- Analyze image metadata and EXIF information
- Perform Error Level Analysis (ELA)
- Detect potential copy-move patterns
- Analyze compression inconsistencies
- Analyze noise inconsistencies
- Localize suspicious evidence where technically possible
- Aggregate forensic evidence
- Present an explainable manipulation assessment

## Evidence Localization

MorphTrace is designed to provide more than an image-level result.

When a forensic technique produces spatially meaningful evidence, the
system should identify and visualize the corresponding suspicious
region.

The system must distinguish between forensic evidence and certainty.
No individual technique should automatically be treated as definitive
proof of manipulation.

## Model Training

The images generated by `scripts/generate_demo_dataset.py` are synthetic
examples for development; they are not CASIA data and must not be used as
a production training set. They are written to `data/demo`. The trainer
also detects the old generated filenames under `data/casia` and refuses
to save a model from them.

Place real, correctly labeled images under `data/casia/Au` and
`data/casia/Tp`. Training requires at least 50 readable images per class,
compares tree and calibrated SVM models with stratified 5-fold
cross-validation, and saves only when balanced accuracy reaches 0.65.
Use `--evaluate-only` to compare algorithms without saving a model.
Before relying on results, validate on separate source images that were
not used for training or model selection.

Classifier scores and forensic signal scores are not proof or calibrated
probabilities. Missing EXIF metadata is also not evidence of manipulation.
